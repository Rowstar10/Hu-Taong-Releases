# Hu Taong

Pong, the Wangsheng Funeral Parlor way. Every version of Hu Taong, ready to play: see
[Releases](https://github.com/Rowstar10/Hu-Taong-Releases/releases).

The easiest way to play is **Toki Hub** ([download](https://github.com/Rowstar10/Toki-Hub-Releases/releases/latest)),
which lists every version and installs any of them. Or download a version's
`Hu-Taong-<version>-windows.zip`, unzip it and run `Hu Taong.exe`; on Android (1.5 on), download its
`Hu-Taong-<version>-android.apk` and open it.

Your settings, stats and replays are kept in `%APPDATA%\HuTaong`, so they carry over between versions.
